# Техническое задание — TaskFlow

## 1. Назначение системы

**TaskFlow** — веб-приложение для отслеживания задач (task tracker) на базе Flask. Позволяет создавать задачи, управлять их жизненным циклом, комментировать и прикладывать файлы.

---

## 2. Технический стек

| Компонент | Технология |
|-----------|-----------|
| Backend | Python 3.10+, Flask 3.x |
| ORM | SQLAlchemy (через Flask-SQLAlchemy) |
| БД | SQLite (dev) |
| Формы | Flask-WTF, WTForms |
| Аутентификация | Session-based (Werkzeug password hashing) |
| Frontend | Jinja2-шаблоны, чистый CSS |

---

### Назначение файлов

| Файл | Содержимое |
|------|-----------|
| `app.py` | Конфигурация Flask, инициализация `db`, регистрация Blueprint, точка запуска |
| `extensions.py` | Объект `db = SQLAlchemy()` — отдельно, чтобы избежать circular imports |
| `models.py` | Классы `Account`, `Task`, `Comment` и их свойства |
| `forms.py` | Все WTForms-классы и константа `ALLOWED_EXTENSIONS` |
| `routes.py` | Blueprint `bp` со всеми `@bp.route(...)` |
| `utils.py` | `active_user()`, декораторы `require_login`/`require_admin`, `save_file()`, `bootstrap_admin()` |

## 4. Роли пользователей

| Роль | Возможности |
|------|-------------|
| **Аноним** | Просмотр публичных задач |
| **User** | Всё + создание/редактирование своих задач, смена статуса (кроме archived), комментирование |
| **Admin** | Всё + управление пользователями, просмотр всей статистики |

---

## 5. Модели данных

### Account (таблица `users`)
- `id`, `username` (unique), `password_hash`, `is_admin`, `created_at`

### Task (таблица `tasks`)
- `id`, `title`, `description`, `status`, `priority`, `is_private`
- `deadline`, `filename`, `original_filename`
- `created_at`, `updated_at`, `author_id` (FK → users)

### Comment (таблица `comments`)
- `id`, `text`, `filename`, `original_filename`
- `created_at`, `author_id` (FK → users), `task_id` (FK → tasks)

---

## 6. Статусы задачи (жизненный цикл)

```
new → in_progress → done → archived
```

| Статус | Описание |
|--------|----------|
| `new` | Только создана |
| `in_progress` | В работе |
| `done` | Выполнена |
| `archived` | В архиве (только автор) |

---

## 7. Приоритеты

`high` (Высокий) / `medium` (Средний) / `low` (Низкий)

---

## 8. Функциональные требования

### 8.1 Аутентификация
- Вход по логину и паролю
- Выход из системы
- При первом запуске создаётся admin с рандомным паролем (выводится в консоль)

### 8.2 Задачи
- Создание задачи: название, описание, приоритет, дедлайн, файл, флаг приватности
- Редактирование своей задачи (автором)
- Просмотр публичных задач (все) + приватных (только автор)
- Личный список задач (`/my-tasks`) — все задачи автора включая приватные и архивные

### 8.3 Статусы
- Любой авторизованный может менять статус задачи на `new / in_progress / done`
- Только автор может переводить в `archived`

### 8.4 Комментарии
- Добавление текстового комментария к задаче
- Прикрепление файла к комментарию
- Просмотр комментариев в хронологическом порядке

### 8.5 Фильтры и поиск (`/tasks`)
- Фильтр по статусу
- Фильтр по приоритету
- Фильтр по диапазону дат дедлайна
- Текстовый поиск по названию и описанию
- Сортировка: новые/старые, по дедлайну, по приоритету, по жизненному циклу

### 8.6 Статистика (`/stats`)
- Количество выполненных задач за неделю
- Количество выполненных задач за месяц
- Распределение по статусам
- Распределение по приоритетам
- Для admin — по всем задачам; для user — только по своим

### 8.7 Управление пользователями (только admin)
- Создание пользователей с выбором роли
- Просмотр списка всех пользователей

## 9. Маршруты

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/` | Редирект на `/tasks` |
| GET/POST | `/login` | Вход |
| GET | `/logout` | Выход |
| GET | `/tasks` | Список публичных задач (с фильтрами) |
| GET | `/my-tasks` | Личный список задач |
| GET/POST | `/tasks/create` | Создать задачу |
| GET | `/tasks/<id>` | Детальный просмотр задачи |
| POST | `/tasks/<id>` | Добавить комментарий |
| POST | `/tasks/<id>/status` | Изменить статус |
| GET/POST | `/tasks/<id>/edit` | Редактировать задачу |
| GET | `/uploads/<filename>` | Скачать файл |
| GET | `/stats` | Статистика |
| GET/POST | `/users/create` | Управление пользователями (admin) |

---

## 10. Безопасность

- CSRF-защита на всех формах (Flask-WTF)
- Пароли хранятся только в виде хешей (Werkzeug PBKDF2)
- Проверка прав доступа к приватным задачам (403 при нарушении)
- Загружаемые файлы: безопасные имена (`secure_filename`), случайные хэш-имена на диске
- Ограничение размера файла: 16 МБ
- Допустимые расширения: png, jpg, jpeg, gif, pdf, txt, doc, docx, zip

При первом запуске в консоль будет выведен пароль администратора.
